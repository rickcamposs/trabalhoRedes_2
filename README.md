## Sobre o trabalho

Este repositório reúne os exercícios do Trabalho 2, que trabalha a programação de redes com os protocolos TCP e UDP, a comunicação cliente-servidor com threads, a análise de tráfego com o Wireshark e a criação de chats em tempo real.

## Estrutura do repositório

| Diretório | Exercício |
|---|---|
| `exercicio1/` | Cliente-Servidor (TCP) |
| `exercicio2/` | Servidor Echo (UDP) |
| `exercicio3/` | Chat em Rede (TCP) |
| `exercicio4/` | Servidor de Hora com Threads (TCP) |
| `exercicio5/` | Análise de tráfego HTTP |
| `exercicio6/` | Estabelecimento e encerramento de conexão TCP |
| `exercicio7/` | Resolução de nomes via DNS |
| `exercicio8/` | Tráfego ICMP (ping) |
| `exercicio9/` | Tráfego DHCP (processo DORA) |
| `exercicio10/` | Chat em Rede com WebSockets |

Cada diretório possui seu próprio `README.md`, com as instruções de execução (comandos, parâmetros e dependências). Nos exercícios 5 a 9, o diretório também contém o arquivo de captura do Wireshark (`.pcapng`) e as imagens das evidências.

## Requisitos

- Sistema operacional Linux
- Python 3.10 ou superior
- Wireshark (para os exercícios 5 a 9)
- Biblioteca `websockets` (exercício 10): `pip install websockets`

## Como executar

Entre no diretório do exercício desejado e siga as instruções do `README.md` correspondente.
